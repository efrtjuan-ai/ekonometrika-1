Merapikan data sebelum meregresi

Regresi yang canggih di atas data kotor tetap menghasilkan sampah. Pembersihan data adalah 60% pekerjaan, dan itu yang diuji di Tugas 2.

CeritaKamu dapat file penjualan 120 outlet. Ada id kembar, wilayah ditulis “ jogja”, “JOGJA”, dan “Jogja ”, promosi bernilai −5, dan umur usaha kosong. Kalau langsung regress, Stata tidak protes, tapi hasilnya menyesatkan.

Alur 5 langkah

1 · Masukkan

import excel, import delimited, use

2 · Kenali

describe, codebook, summarize, tab

3 · Deteksi masalah

duplikat, typo kategori, nilai tak masuk akal, missing

4 · Perbaiki

duplicates drop, replace, strtrim, encode

5 · Beri label & simpan

label variable, save

Kode lengkap, baris demi baris

* --- 1. Masukkan data ---
import excel "Dataset.xlsx", sheet("data_raw") firstrow clear
import delimited "data.csv", clear          // kalau CSV

* --- 2. Kenali ---
describe                     // tipe variabel, jumlah obs
codebook, compact            // ringkasan tiap variabel
summarize                    // mean, sd, min, max
summarize penjualan, detail  // + persentil, skewness, kurtosis
tabulate wilayah, missing

* --- 3. Deteksi ---
duplicates report            // baris kembar sempurna
duplicates report id         // id kembar
misstable summarize          // pola missing
list id promosi if promosi < 0 | promosi > 60

* --- 4. Perbaiki ---
duplicates drop
replace wilayah = strproper(strtrim(wilayah))   // " jogja" -> "Jogja"
encode wilayah, gen(wil)                         // teks -> angka berlabel
replace promosi = . if promosi < 0 | promosi > 60
destring harga, replace ignore(",")              // teks angka -> numerik

* --- Variabel baru ---
generate lprice   = ln(price)
generate sqrft2   = sqrft^2
generate besar    = (sqrft > 2000) if !missing(sqrft)   // dummy 0/1
egen rata_wil     = mean(penjualan), by(wil)
drop sqrft2
rename lotsize luas_tanah

* --- 5. Label & simpan ---
label variable lprice "Log harga rumah"
label define ya 0 "Tidak" 1 "Ya"
label values besar ya
save "data_bersih.dta", replace
Jebakan dummy & missingDi Stata, nilai missing (.) dianggap lebih besar dari angka apa pun. Jadi gen besar = (sqrft > 2000) akan memberi 1 untuk baris yang missing. Selalu tambah if !missing(sqrft).

Bab 3 · Sesi 1

Apa itu ekonometrika?

Ekonom sering bilang “kalau luas rumah naik, harga naik”. Ekonometrika menjawab: naik berapa, dan seberapa yakin kita.

Pemanasan dari kelasTiga studi JMAP (2023) di DIY bertanya: berapa lama properti “terekspos” di pasar sebelum laku? Jawabannya berbeda: ruko, rumah tinggal, tanah kosong masing-masing punya faktor penting sendiri, bahkan jarak ke tempat ibadah ikut signifikan. Pertanyaan kritisnya: benarkah jarak itu menyebabkan lambat laku, atau ia mewakili hal lain yang tidak terlihat model?

Tiga pekerjaan ekonometrika (Wooldridge)

Mengestimasi

Berapa tambahan harga per m² bangunan?

Menguji teori

Apakah suku bunga deposito benar memengaruhi lama jual?

Mengevaluasi kebijakan

Apakah insentif PPN DTP menaikkan penjualan rumah?

Dari teori ke model

Teori ekonomi itu deterministik: harga = f(luas). Dunia nyata tidak serapi itu, jadi kita tambahkan galat u yang menampung semua faktor lain yang tidak kita amati.

Teori: harga = f(luas)  →  Model: harga = β₀ + β₁·luas + u

Kausalitas & ceteris paribus

Ceteris paribus artinya “hal lain dianggap tetap”. Korelasi antara jumlah kafe dan harga rumah tidak berarti kafe menyebabkan harga naik; bisa jadi lokasi strategis menarik keduanya.

Asosiasi ≠ kausalitasKita baru bisa membaca β₁ sebagai efek kausal jika faktor lain di u tidak berkorelasi dengan x. Syarat ini akan muncul terus dengan nama zero conditional mean: E(u|x) = 0.

Langkah analisis empiris

  1. Pertanyaan: apa yang ingin diketahui?
  2. Spesifikasi: variabel apa, bentuk fungsi apa, tanda yang diharapkan.
  3. Data: kumpulkan, bersihkan (Bab 2).
  4. Estimasi: OLS, MLE, dll.
  5. Inferensi: uji hipotesis, interval kepercayaan.
  6. Robustness: uji asumsi, spesifikasi alternatif.
  7. Narasi: tulis hasil dengan konteks ekonomi.

Bab 4 · Sesi 2

Statistik yang wajib kamu ingat

Ekonometrika berdiri di atas empat batu: rata-rata, varians, korelasi, dan uji hipotesis. Kita segarkan lagi dengan cepat.

Ukuran pemusatan & sebaran

KonsepRumusBahasa manusia
Rata-ratax̄ = Σxᵢ / nTitik keseimbangan data
Varianss² = Σ(xᵢ − x̄)² / (n − 1)Rata-rata jarak kuadrat dari pusat
Simpangan bakus = √s²Sebaran dalam satuan asli
KovariansΣ(xᵢ−x̄)(yᵢ−ȳ)/(n−1)Apakah x dan y bergerak searah?
Korelasir = cov(x,y)/(sₓ·s_y)Kovarians yang dibakukan, −1 sampai 1

Uji hipotesis dalam 4 langkah

  1. H₀ (status quo, misal “tidak ada pengaruh”: β = 0) dan H₁ (β ≠ 0).
  2. Pilih tingkat signifikansi α, biasanya 5%.
  3. Hitung statistik uji, misalnya t = (estimasi − nilai H₀) / standard error.
  4. Bandingkan: jika |t| > t-kritis, atau p-value < α, tolak H₀.
p-value, versi paling sederhana“Kalau H₀ benar, seberapa aneh data seperti ini bisa muncul?” p kecil = data sangat aneh untuk dunia H₀ → kita meragukan H₀.
🧪 Lab: geser t, lihat p-value interaktif

Di Stata

bcuse hprice1, clear
summarize price sqrft, detail
correlate price sqrft bdrms lotsize      // matriks korelasi
pwcorr price sqrft bdrms, sig star(.05)  // + p-value dan bintang
ttest price == 300                       // apakah rata-rata harga = 300?
ttest price, by(colonial)                // beda rata-rata dua kelompok
Dua kesalahan klasik(1) “p = 0,03 berarti peluang H₀ benar 3%.” Salah. p dihitung dengan asumsi H₀ benar. (2) “Tidak signifikan berarti tidak ada pengaruh.” Belum tentu, bisa jadi sampel terlalu kecil.

Hasil uji: t = 1,4 dan p = 0,17 pada α = 5%. Kesimpulannya?

Bab 5 · Sesi 3

Regresi linear sederhana

Satu y, satu x, satu garis. Tapi garis yang mana? Jawabannya: garis yang membuat total kesalahan kuadrat paling kecil.

CeritaSeorang penilai properti ingin rumus cepat: “setiap tambahan 1 sqft luas bangunan menambah harga berapa?” Ia punya 88 transaksi. Ia menggambar scatter plot, lalu mencari garis terbaik.

PRF vs SRF

PRF (populasi)

y = β₀ + β₁x + u
Garis “sejati” yang tak pernah kita lihat. u = galat.

SRF (sampel)

ŷ = β̂₀ + β̂₁x
Garis hasil estimasi dari data. û = y − ŷ = residual.

🔬 Bedah rumus garis prediksi · klik tiap simbol
🔬 Bedah rumus residual · klik tiap simbol
🔬 Bedah PRF · klik tiap simbol
Galat vs residualGalat (u) tidak bisa diamati. Residual (û) bisa dihitung. Topi “^” = hasil estimasi.

Ide OLS: jumlah kuadrat residual sekecil mungkin

min Σ ûᵢ² = Σ (yᵢ − β̂₀ − β̂₁xᵢ)²
🔬 Bedah rumus · klik tiap simbol

Turunkan terhadap β̂₀ dan β̂₁, samakan nol, dan kamu dapat:

β̂₁ = Σ(xᵢ−x̄)(yᵢ−ȳ) / Σ(xᵢ−x̄)²   |   β̂₀ = ȳ − β̂₁x̄
🔬 Bedah rumus · klik tiap simbol

Artinya β̂₁ = kovarians(x,y) / varians(x). Garis OLS selalu melewati titik rata-rata (x̄, ȳ).

🧪 Lab: bangun garis OLS sendiri klik kanvas untuk tambah titik

Coba: aktifkan “garis tebakanku” dan geser. SSR tebakanmu tidak akan pernah lebih kecil dari SSR OLS. Lalu tambah outlier dan lihat garisnya “tertarik”.

Ukuran kecocokan: R²

SST = SSE + SSR   →   R² = SSE/SST = 1 − SSR/SST
🔬 Bedah rumus · klik tiap simbol

SST = total variasi y, SSE = variasi yang dijelaskan model, SSR = variasi sisa. R² = 0,63 berarti 63% variasi harga dijelaskan oleh luas bangunan.

Hati-hati istilahWooldridge memakai SSE = explained, SSR = residual. Buku lain (Gujarati) kadang terbalik: ESS dan RSS. Cek definisinya, jangan hafal singkatannya.

Asumsi SLR.1–SLR.5

AsumsiIsiKalau gagal…
SLR.1Linear dalam parameterModel salah bentuk
SLR.2Sampel acakBias seleksi
SLR.3x bervariasiβ̂₁ tidak bisa dihitung (bagi nol)
SLR.4E(u|x) = 0β̂ bias, masalah paling serius
SLR.5Var(u|x) = σ² (homoskedastis)β̂ tetap tak bias, tapi SE salah

Bab 6 · Sesi 4–5 & 8

Regresi berganda: menahan hal lain tetap

Rumah besar biasanya punya lebih banyak kamar. Kalau hanya meregresi harga pada kamar, efek luas “menumpang” di koefisien kamar. Regresi berganda memisahkannya.

y = β₀ + β₁x₁ + β₂x₂ + … + βₖxₖ + u
🔬 Bedah rumus · klik tiap simbol

βⱼ = efek parsial: perubahan y jika xⱼ naik satu unit, dengan x lain tetap. Inilah ceteris paribus versi statistik.

Partialling out (Frisch–Waugh)

Koefisien bdrms dalam regress price sqrft bdrms sama persis dengan dua langkah ini:

  1. Regresikan bdrms pada sqrft, ambil residualnya (bagian bdrms yang tidak dijelaskan luas).
  2. Regresikan price pada residual itu.
bcuse hprice1, clear
regress price sqrft bdrms
regress bdrms sqrft
predict r_bdrms, residuals
regress price r_bdrms          // koefisien = koefisien bdrms di atas!

Omitted variable bias (OVB)

Model benar: y = β₀ + β₁x₁ + β₂x₂ + u. Kalau x₂ dibuang, slope sederhana menjadi:

E(β̃₁) = β₁ + β₂·δ̃₁   (δ̃₁ = slope regresi x₂ pada x₁)
🔬 Bedah rumus · klik tiap simbol
corr(x₁,x₂) > 0corr(x₁,x₂) < 0
β₂ > 0bias ke atas (+)bias ke bawah (−)
β₂ < 0bias ke bawah (−)bias ke atas (+)
ContohRegresi price hanya pada bdrms. Luas (x₂) berpengaruh positif pada harga (β₂>0) dan berkorelasi positif dengan jumlah kamar. Maka koefisien bdrms terlalu besar (bias ke atas). Coba jalankan reg price bdrms vs reg price bdrms sqrft, lalu bandingkan koefisien bdrms-nya.

Asumsi MLR & Teorema Gauss–Markov

  • MLR.1–4 (linear, sampel acak, tidak ada multikolinearitas sempurna, E(u|x)=0) → OLS tak bias.
  • + MLR.5 homoskedastis → OLS adalah BLUE: Best Linear Unbiased Estimator (varians terkecil di antara estimator linear tak bias).
  • + MLR.6 u ~ Normal → uji t dan F berlaku persis di sampel kecil.
Var(β̂ⱼ) = σ² / [ SSTⱼ · (1 − Rⱼ²) ]
🔬 Bedah rumus · klik tiap simbol

Varians mengecil jika σ² kecil, variasi xⱼ besar (SSTⱼ), dan xⱼ tidak terlalu mirip regresor lain (Rⱼ² kecil). Rⱼ² tinggi = multikolinearitas.

Sifat aljabar (selalu benar, tanpa asumsi)

  • Σûᵢ = 0  ·  Σxᵢⱼûᵢ = 0  ·  titik rata-rata ada di bidang regresi  ·  R² tidak turun saat variabel ditambah.

Di Stata

estimates store m1
regress price sqrft bdrms
estimates store m2
estimates table m1 m2, b(%9.3f) se stats(N r2 r2_a)   // bandingkan model

Bab 8 · Sesi 6

Log, elastisitas & dummy

“Linear” artinya linear dalam parameter, bukan dalam variabel. Jadi kita bebas memakai ln, kuadrat, dan dummy, asalkan membacanya dengan benar.

Tabel sakti interpretasi log

🔬 Bedah model log–log · klik tiap simbol
ModelyxArti β₁
Level–levelyxx +1 unit → y + β₁ unit
Log–level (log-lin)ln yxx +1 unit → y + (100·β₁)%
Level–log (lin-log)yln xx +1% → y + (β₁/100) unit
Log–logln yln xx +1% → y + β₁% (elastisitas)
🧮 Lab: penerjemah koefisien isi & baca
Koreksi untuk koefisien besar & dummyPendekatan 100·β akurat hanya jika β kecil (< 0,1). Rumus persis pada model log–level: %Δy = 100·(eβ − 1). Contoh β = 0,25 → bukan 25% tapi 28,4%.

Kuadrat & titik balik

y = β₀ + β₁x + β₂x² + u  →  Δy/Δx = β₁ + 2β₂x  ·  titik balik x* = −β₁ / (2β₂)

Contoh: harga terhadap umur bangunan bisa turun lalu naik lagi (bangunan “heritage”).

Variabel dummy

  • Dummy = 0/1. Koefisiennya = selisih rata-rata y antara kelompok 1 dan kelompok dasar, ceteris paribus.
  • Untuk kategori dengan g kelompok, masukkan g − 1 dummy. Memasukkan semua = dummy variable trap (multikolinearitas sempurna).
  • Interaksi dummy × x membuat kemiringan berbeda antar kelompok.

Bab 10 · Sesi 10

Maximum likelihood: parameter mana yang paling mungkin?

OLS bertanya “garis mana yang galatnya terkecil?”. MLE bertanya “nilai parameter mana yang membuat data yang kita lihat paling mungkin terjadi?”.

Cerita koinDari 10 lemparan koin keluar 7 angka. Kalau p(angka) = 0,5, peluang hasil ini 0,117. Kalau p = 0,7, peluangnya 0,267, lebih besar. MLE memilih p yang membuat peluang itu maksimum, ternyata tepat 7/10 = 0,7.
🧪 Lab: mendaki bukit likelihood geser p

Langkah umum

  1. Tentukan distribusi y (Bernoulli, Poisson, Normal, …).
  2. Tulis likelihood: L(θ) = Π f(yᵢ | xᵢ, θ).
  3. Ambil log agar perkalian menjadi penjumlahan: ℓ(θ) = Σ ln f(yᵢ | xᵢ, θ).
  4. Cari θ yang memaksimumkan ℓ. Stata melakukannya secara iteratif (“Iteration 0, 1, 2 …”).
θ̂MLE = arg max Σ ln f(yᵢ | xᵢ; θ)
🔬 Bedah rumus · klik tiap simbol

Sifat & alat uji

  • Pada sampel besar MLE konsisten, normal asimtotik, dan efisien.
  • Pada regresi linear dengan galat normal, MLE untuk β = OLS.
  • Tiga uji klasik: Wald (test), Likelihood Ratio (lrtest), LM/score.
  • Kecocokan: log likelihood, pseudo R², AIC/BIC (estat ic, makin kecil makin baik).
LR = 2 (ℓur − ℓr) ~ χ²q
bcuse mroz, clear
logit inlf nwifeinc educ exper age kidslt6
estimates store full
logit inlf nwifeinc educ exper
estimates store restr
lrtest full restr                 // H0: age & kidslt6 tidak perlu
estat ic                          // AIC & BIC

Bab 11 · Sesi 11

Kalau y hanya ya atau tidak: logit & probit

Laku dalam 6 bulan atau tidak? Mengambil KPR atau tidak? Variabel dependen biner butuh model yang peluangnya tetap di antara 0 dan 1.

Masalah Linear Probability Model (LPM)

regress laku x boleh saja dan mudah dibaca, tapi prediksinya bisa < 0 atau > 1 dan pasti heteroskedastis. Solusinya: bungkus indeks linear dengan fungsi berbentuk S.

P(y=1|x) = G(β₀ + β₁x₁ + …)  ·  Logit: G(z)=eᶻ/(1+eᶻ)  ·  Probit: G(z)=Φ(z)
🔬 Bedah rumus · klik tiap simbol
🧪 Lab: kurva S peluang rumah laku geser β

Membaca hasil: pakai efek marginal!

Koefisien logit/probit hanya jelas tandanya. Besarnya dibaca melalui efek marginal: ∂P/∂x = g(xβ)·β, yang berbeda di setiap titik x (lihat garis singgung di lab).

  • Odds ratio (logit): eβ. OR = 1,4 → odds laku naik 40% per unit x.
  • Aturan kasar: βlogit ≈ 1,6 × βprobit. Efek marginal keduanya biasanya mirip.
bcuse mroz, clear       // inlf = 1 jika perempuan bekerja
regress inlf nwifeinc educ exper expersq age kidslt6 kidsge6, robust   // LPM
logit  inlf nwifeinc educ exper expersq age kidslt6 kidsge6
logit  inlf nwifeinc educ exper expersq age kidslt6 kidsge6, or        // odds ratio
margins, dydx(*)                     // AME: average marginal effect
probit inlf nwifeinc educ exper expersq age kidslt6 kidsge6
margins, dydx(educ) atmeans          // MEM: di rata-rata
margins, at(educ=(8 12 16))          // peluang prediksi di beberapa nilai
estat classification                 // % prediksi benar (setelah logit)
predict phat, pr

Jam kerja per tahun banyak bernilai 0 lalu positif kontinu. OLS bias; Tobit menggabungkan “apakah positif” dan “seberapa besar”.

Bab 12 · Sesi 12

Pilihan lebih dari dua: multinomial & ordered

Membeli rumah tapak, apartemen, atau menyewa? Itu tidak berurutan. Menilai kondisi bangunan “buruk / sedang / baik”? Itu berurutan. Beda sifat, beda model.

Multinomial logit (mlogit)

Kategori tanpa urutan. Satu kategori menjadi basis; ada satu set β untuk setiap kategori lain. Asumsi IIA (tidak bergantung alternatif lain).

Ordered logit/probit (ologit)

Kategori berurutan. Satu set β + beberapa cut-point (ambang) yang memisahkan kategori.

mlogit: P(y=j) = exp(xβⱼ) / Σₕ exp(xβₕ)  ·  ologit: y = j jika κⱼ₋₁ < xβ + e ≤ κⱼ
* --- Multinomial: jenis asuransi (Indemnity, Prepaid, Uninsure)
webuse sysdsn1, clear
mlogit insure age male nonwhite i.site, baseoutcome(1)
mlogit, rrr                               // relative risk ratio
margins, dydx(age) predict(outcome(2))    // efek pada P(Prepaid)

* --- Ordered: catatan reparasi mobil 1-5
webuse fullauto, clear
ologit rep77 foreign length mpg
margins, dydx(foreign) predict(outcome(5))  // efek pada P(sangat baik)
oprobit rep77 foreign length mpg
brant                                        // uji parallel lines (butuh paket SPost13)
Membaca koefisien ologitβ positif artinya kecenderungan ke kategori lebih tinggi. Peluang kategori tertinggi naik, peluang terendah turun, sementara kategori tengah bisa naik atau turun. Karena itu gunakan margins per outcome.

Bab 13 · Sesi 13

Data hitungan & bias seleksi

Poisson: y = 0, 1, 2, 3, …

Jumlah penawaran yang diterima sebuah listing, jumlah transaksi per kecamatan, jumlah penangkapan. Nilai tidak negatif dan bulat.

E(y|x) = exp(β₀ + β₁x₁ + …)  →  x +1 unit ⇒ E(y) berubah ≈ 100·β % (persis: 100·(eβ−1)%)
  • Asumsi Poisson: mean = varians (equidispersion). Jika varians ≫ mean (overdispersion), pakai nbreg atau minimal robust SE.
  • Banyak nol berlebih → pertimbangkan zip/zinb.
bcuse crime1, clear     // narr86 = jumlah penangkapan 1986
summarize narr86, detail   // bandingkan mean dan varians
poisson narr86 pcnv avgsen tottime ptime86 qemp86 inc86 black hispan born60, vce(robust)
poisson, irr               // incidence rate ratio = e^b
estat gof                  // goodness of fit (tanpa robust)
nbreg narr86 pcnv avgsen tottime ptime86 qemp86 inc86 black hispan born60
margins, dydx(pcnv)

Heckman: sampel tidak acak

CeritaKamu ingin menaksir faktor harga sewa, tetapi hanya rumah yang benar-benar disewakan yang punya data sewa. Pemilik yang menilai rumahnya “terlalu berharga untuk disewakan” tidak masuk sampel. OLS pada sampel tersisa bisa bias.

Heckman dua tahap: (1) probit persamaan seleksi (apakah diamati?), menghasilkan inverse Mills ratio λ; (2) regresi persamaan utama dengan λ sebagai regresor tambahan. Jika koefisien λ signifikan, bias seleksi memang ada.

Syarat pentingPersamaan seleksi sebaiknya punya minimal satu variabel yang tidak ada di persamaan utama (exclusion restriction), misalnya jumlah anak kecil memengaruhi keputusan bekerja tetapi tidak upah.
bcuse mroz, clear
* Upah (lwage) hanya teramati untuk perempuan yang bekerja (inlf==1)
heckman lwage educ exper expersq, ///
        select(inlf = educ exper expersq nwifeinc age kidslt6 kidsge6) twostep
* baris "lambda" = koefisien inverse Mills ratio
heckman lwage educ exper expersq, ///
        select(inlf = educ exper expersq nwifeinc age kidslt6 kidsge6)   // versi MLE

Mean jumlah kunjungan = 2,1 dan varians = 9,8. Model yang lebih tepat?

Time series & ARIMA: meramal dari masa lalu

Indeks harga properti bulan ini mirip bulan lalu. Informasi “ingatan” itulah yang dipakai ARIMA untuk memprediksi.

Tiga huruf, tiga ide

AR(p) · AutoRegressive

Nilai sekarang bergantung pada nilai sebelumnya: yₜ = φ₁yₜ₋₁ + … + εₜ

I(d) · Integrated

Berapa kali data di-differencing (Δyₜ = yₜ − yₜ₋₁) agar stasioner.

MA(q) · Moving Average

Nilai sekarang bergantung pada kejutan sebelumnya: yₜ = εₜ + θ₁εₜ₋₁ + …

ARIMA(p,d,q): Δᵈyₜ = c + φ₁Δᵈyₜ₋₁ + … + φₚΔᵈyₜ₋ₚ + εₜ + θ₁εₜ₋₁ + … + θ_qεₜ₋_q
🔬 Bedah ARMA(1,1) · klik tiap simbol

Stasioneritas: syarat pertama

Seri stasioner punya rata-rata dan varians yang stabil. Harga rumah biasanya naik terus (tren), jadi tidak stasioner. Regresi dua seri tak stasioner bisa menghasilkan spurious regression: R² tinggi padahal tidak ada hubungan.

Uji akar unit (ADF)H₀: ada akar unit (tidak stasioner). p < 0,05 → tolak H₀ → stasioner. Kalau gagal tolak, differencing dan uji lagi.

Data panel: fixed atau random effects?

Mengamati kabupaten yang sama tiap tahun memberi kekuatan super: kita bisa menghapus faktor tetap yang tidak terlihat, misalnya “daya tarik” sebuah daerah.

yᵢₜ = β₀ + β₁xᵢₜ + aᵢ + uᵢₜ   (aᵢ = efek individu yang tetap sepanjang waktu)

EstimatorIdeKapan cocok
Pooled OLSAbaikan struktur panelJika aᵢ tidak ada/tidak berkorelasi (jarang)
